# java.lang.reflect.Method（JDK原生反射Method）

`Method`代表一个类上的方法，**JDK反射API**，可以拿到方法几乎全部元数据、注解、修饰符，还可以执行方法。

> 来源：`MethodSignature#getMethod()` 获取得到。

## 一、获取方法基础信息

| 方法                     | 作用                                                         |
| ------------------------ | ------------------------------------------------------------ |
| `getName()`              | 获取方法名                                                   |
| `getModifiers()`         | 获取修饰符int，配合`Modifier`解析：public/private/static/final等 |
| `getDeclaringClass()`    | 获取该方法属于哪个类                                         |
| `getReturnType()`        | 获取方法返回值类型 `Class<?>`                                |
| `getGenericReturnType()` | 获取泛型返回类型（如`List<User>`）                           |

## 二、获取参数相关信息

| 方法                         | 作用                                                         |
| ---------------------------- | ------------------------------------------------------------ |
| `getParameterTypes()`        | 参数类型数组 `Class<?>[]`，擦除泛型                          |
| `getGenericParameterTypes()` | 获取带泛型的参数类型                                         |
| `getParameterCount()`        | 参数个数                                                     |
| `getParameters()`            | 返回`Parameter[]`，可以拿到参数名（需要编译开启 `-parameters`） |

> 注意：原生JDK的`Method`**没有getParameterNames()**，这是AspectJ的`MethodSignature`提供的。JDK要拿参数名需要`getParameters()[i].getName()`。

## 三、获取异常信息

```
Class<?>[] getExceptionTypes()           // 声明抛出的异常（泛型擦除）
Type[] getGenericExceptionTypes()        // 带泛型的异常
```

## 四、获取注解（AOP高频使用）

```
// 获取本方法上该注解（直接标注，不继承）
<T extends Annotation> T getAnnotation(Class<T> annotationClass);

Annotation[] getDeclaredAnnotations();   // 所有直接注解
boolean isAnnotationPresent(Class<? extends Annotation> ann); // 是否存在注解
```

> AOP场景最常用：判断目标方法是否加了某个自定义注解。

## 五、判断方法特性

```
isVarArgs()      // 是否可变参数方法 void test(String... args)
isDefault()      // 是否接口的default方法
```

## 六、调用执行方法

```
// obj：调用哪个对象；args入参；静态方法obj传null
Object invoke(Object obj, Object... args) throws IllegalAccessException, InvocationTargetException;
```

## 七、和 MethodSignature 的对比（重点）

1. **Method：JDK原生反射对象**，能力全，可以拿注解、修饰符、异常、执行方法。
2. **MethodSignature：AspectJ包装**，只是对Method部分API做代理，**不能直接拿注解、修饰符、异常，不能invoke执行**，需要拿到内部的`Method`。

```
MethodSignature ms = (MethodSignature) joinPoint.getSignature();
Method method = ms.getMethod();
// 读取注解必须靠Method
MyAnnotation anno = method.getAnnotation(MyAnnotation.class);
```

## 完整示例

```
Method method = ms.getMethod();

//基础信息
String methodName = method.getName();
Class<?> clazz = method.getDeclaringClass();
Class<?> returnType = method.getReturnType();

//参数
Class<?>[] paramTypes = method.getParameterTypes();

//注解
if(method.isAnnotationPresent(MyAnn.class)){
    MyAnn ann = method.getAnnotation(MyAnn.class);
}

//修饰符
int modifier = method.getModifiers();
System.out.println(Modifier.isPublic(modifier));
```

## 快速记忆

- ✅ **Method能干而MethodSignature干不了的：读取注解、修饰符、抛出异常、invoke反射调用方法、判断可变参数。**
- ✅ MethodSignature只做简单代理，复杂反射操作，都要拿到原生`Method`。

> 坑：SpringAOP中如果是接口，`method`是接口上的方法对象，不是实现类，注解如果写在实现类上，接口Method拿不到注解。
